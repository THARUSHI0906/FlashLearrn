# FlashLearrn
Flashcard Learning &amp; Quiz Mobile App
## 💡 Project Idea & Concept
**FlashLearn** is designed to solve the problem of scattered study materials and inefficient revision methods for university students. Instead of managing papers or complex cloud-based tools, students can instantly create digital flashcards structured by course decks (Question on the front, Answer on the back). The app features an interactive flip-card interface for active recall and tracks correct/incorrect attempt scores during study sessions. Powered by a local SQLite database, it operates entirely offline, ensuring complete data privacy and accessibility anytime without requiring an internet connection or user account.
